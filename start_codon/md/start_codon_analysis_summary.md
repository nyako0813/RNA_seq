# M. acetivorans 開始コドン検証パイプライン — 分析手法・結果まとめ

## 1. 目的

NCBI RefSeqアノテーション(GCF_000007345.1)における *Methanosarcina acetivorans* の全タンパク質コード遺伝子について、注釈された翻訳開始点(開始コドン)が正しいかを、RNA-seqカバレッジとBLASTオルソログ比較という2種類の独立した証拠で検証する。RefSeqの相同性ベースの遺伝子予測は、必ずしも実際のゲノム配列上で正準な開始コドン(ATG/GTG/TTG)を強制していないため、注釈上の開始点がオルソログや転写開始点と食い違うケースを網羅的に洗い出すことを目的とする。

## 2. 入力データ

| データ | 内容 |
|---|---|
| GFFアノテーション | `start_codon/data/methanosarcina_acetivorans/ncbi_dataset/data/GCF_000007345.1/genomic.gff` |
| ゲノムFASTA | `rnaseq_requantification/genome/NC_003552.1.fna` |
| RNA-seq BAM | `rnaseq_requantification/bam/` 配下6サンプル。元は炭素源(酢酸/メタノール)×呼吸条件(humus-respiratory/no-respiratory)の計4条件・11サンプルが存在するが、現在は`no-respiratory`条件2種(acetate×3, methanol×3)のみが残っており、`humus-respiratory`条件2種(acetate×3, methanol×2)は意図的に削除済み(§8参照) |
| オルソログ蛋白質DB | Methanosarcina属6種(*M. mazei, M. barkeri, M. thermophila, M. vacuolata, M. siciliae, M. horonobensis*、*M. acetivorans*自身は除く)の`protein.faa`を連結、21,734配列。`makeblastdb`でBLAST DB化。 |

## 3. 手法

パイプライン本体は `start_codon/find_true_start_codons.py`。遺伝子1件ごとに以下を実施する。

1. **GFFからの遺伝子抽出**: `CDS`行から遺伝子座標・現行開始コドンを取得。`pseudo=true`とマークされた偽遺伝子(163件)、およびIS転移酵素等でORF-A/ORF-Bにフレームシフトで分割され同一locus_tagを共有するCDS(19件)は除外。`old_locus_tag`は`CDS`行には存在せず`gene`行にのみ存在するため、locus_tag→old_locus_tagのルックアップを別途`gene`行から構築。
2. **上流候補コドンの探索**: 現行開始点から上流方向に、ストップコドンまたは隣接遺伝子との重なりに達するまでの候補開始コドン(ATG/GTG/TTG)を列挙。
3. **RNA-seq証拠**: 6サンプルのBAMについて`samtools depth`でカバレッジを取得し、各候補位置の前後でのカバレッジの「ステップ比」(候補位置より下流の深度 ÷ 上流の深度)を算出。ステップ比が閾値3.0を超える最有力候補を`rna_best_pos`として記録。
4. **BLAST証拠**: 各遺伝子のタンパク質配列をオルソログDBに対して`blastp`検索し、最良ヒットのアラインメント開始位置(`qstart`)・同一性(`pident`)から、オルソログのN末端と一致する開始点(`blast_supported_pos`)を推定。
5. **判定**: RNA-seq・BLAST両証拠を突き合わせ、以下4分類のいずれかを付与。

| 判定 | 意味 |
|---|---|
| 現行アノテーションを支持 | 両証拠(または片方)が現行開始点を支持、あるいは矛盾する証拠なし |
| 中確信度: 上流への延長の可能性(片方の証拠のみ) | RNA-seqかBLASTの一方のみが上流延長を示唆 |
| 高確信度: 上流への延長を提案(RNA-seq・BLAST一致) | 両証拠が同一の上流候補を独立に支持 |
| 要確認: RNA-seqとBLASTが異なる候補を支持 | 両証拠が上流延長を示唆するが、支持する具体的な位置が食い違う |

## 4. 実行前の検証(スモークテスト)

本番実行前に、対象タンパク質MA_4115とその近傍4遺伝子(MA_2894, MA_1974, MA_0826, MA_0074/radB)によるミニテストを実施し、パイプラインが実データで正常動作することを確認した。この過程で2件の知見を得た。

- 偽遺伝子(`pseudo=true`)がフィルタされておらず、無意味な開始コドンを拾う不具合を発見・修正。
- 実タンパク質コード遺伝子4,702件中125件(約2.7%)で、現行アノテーション自体の開始コドンが非正準(ATG/GTG/TTG以外)であることが判明。ゲノムFASTA・GenBankフラットファイル双方で確認し、ファイル不整合ではないことを検証済み。RefSeqの相同性ベース遺伝子予測が正準開始コドンを強制していないことに起因すると考えられる。

## 5. フル実行結果

全4,683遺伝子(4,702実タンパク質コード遺伝子 − 19件のフレームシフト連結CDS除外)を処理。

| 判定 | 件数 | 割合 |
|---|---|---|
| 現行アノテーションを支持 | 3,427 | 73.2% |
| 中確信度(片方の証拠のみ) | 1,109 | 23.7% |
| 高確信度(RNA-seq・BLAST一致) | 113 | 2.4% |
| 要確認(RNA-seqとBLASTが異なる候補を支持) | 34 | 0.7% |

補足指標:

- 現行開始コドンが非正準: 106/4,683(2.26%、うち95件は「支持」判定 — 基準点自体が非正準なため信頼度は見た目より低い)
- BLAST支持位置と現行開始位置が不一致(=中確信度+高確信度+要確認の合計): 1,256/4,683(26.8%)
- 延長コドン数(現行位置との差): 中央値8コドン、平均13.8コドン。1〜3コドンの小さなズレが最頻(3コドン: 182件)

フル実行にあたり、ミニ5遺伝子スモークテストでは顕在化しなかった2件のバグを新たに発見・修正した(上記「手法」節に記載の偽遺伝子・old_locus_tagの扱いの一部、およびフレームシフト連結CDS19件によるクラッシュ)。修正後、ミニ5遺伝子の結果は完全に再現され、回帰の問題がないことを確認済み。

## 6. 「要確認」34件の深掘り調査

RNA-seqとBLASTが異なる候補を支持する34件について、`samtools depth`による塩基単位のカバレッジプロファイルと、隣接遺伝子の座標情報を用いて追加検証を行った。

### 第1段階(深度プロファイル・BLAST qstartによる分類)

| 分類 | 件数 | 判断根拠 |
|---|---|---|
| 真の代替候補 | 6 | RNA-seq候補とBLAST支持位置が数bp差で近接、かつ双方の証拠が独立に妥当 |
| アーティファクト | 5 | 異常に高いカバレッジ(反復配列・マルチマッピングの疑い)、または高発現遺伝子自身の減衰テールをステップと誤認識、あるいはBLAST証拠が極めて弱い(qstartが大きい・同一性が低い)ケース |
| 判断保留 | 23 | 両証拠が食い違い、どちらか一方に確定する根拠が不足 |

この段階で、当初懸念していた「RNA-seq候補が隣接遺伝子自身の開始点への読み流れである」というメカニズムは34件中どれにも該当しないことを確認した(最も近いケースでも隣接遺伝子の開始点まで137bp離れていた)。

### 第2段階 Task A: 判断保留23件のうちBLAST証拠が弱いグループの再評価

「真の代替候補」6件の実測範囲(BLAST qstart≦19、同一性≧86.5%)を基準として、これを満たさない17件を「BLAST証拠が実質的に独立支持とみなし難い」ケースとして再評価。RNA-seq単独の証拠の質(深度の残存率・立ち上がりの明瞭さ)を個別に検討した結果、1件(MA_RS22115)はRNA-seq単独でも明瞭なステップ(候補位置で現行の56.8%の深度が残存し、70bpでは2%まで崩落)を示すため「中確信度相当」に格上げした。残り16件は減衰テールに近く判断保留のまま。

### 第2段階 Task B: 遠方カバレッジの再上昇チェック

現行開始位置から70bp・150bp・300bp地点でのカバレッジを追加取得し、各遺伝子の最近傍遺伝子までの距離の半分より手前で説明のつかない深度の再上昇がないかを34件全件で確認した。18件で該当し、うち4件は第1段階で「真の代替候補」と判定した6件に含まれていた。これらについては位置一致・BLAST根拠自体は変わらないため判定は維持しつつ、「広く転写されている」という遠方カバレッジの解釈は撤回し、近傍の未同定転写物やアンチセンス転写の影響を受けている可能性を注記した。

### 最終分類(34件)

| 最終分類 | 件数 |
|---|---|
| 真の代替候補 | 6(うち4件は遠方シグナルに関する注記付き) |
| 中確信度相当(格上げ) | 1 |
| 判断保留 | 22 |
| アーティファクト | 5 |

## 8. 未解決事項・今後の課題

- 判断保留として残る22件は、RNA-seqとBLASTの証拠だけでは確定できない。5'RACEやN末端シークエンシング等の実験的検証が次のステップとして妥当。
- 非正準開始コドンで「支持」と判定された95件のうち、上位15件(BLAST同一性順)のみ簡易チェック済み(14/15でBLAST qstart=1、N末端一致を確認)。残り80件は未チェック。
- **RNA-seq BAMは11サンプル中6サンプルのみを使用**。元々の実験デザインは炭素源(酢酸/メタノール)×呼吸条件(humus-respiratory/no-respiratory)の計4条件・11サンプルだが、現在残っているのは`no-respiratory`条件2種(acetate_no-respiratory×3, methanol_no-respiratory×3)の全6サンプルのみで、`humus-respiratory`条件2種(acetate_humus-respiratory×3, methanol_humus-respiratory×2)の計5サンプルは削除されている。この削除は意図的なものであることを確認済みだが、**炭素源ではなく「呼吸条件」の軸が丸ごと欠落している**点に注意。`humus-respiratory`条件下でのみ発現する遺伝子があれば、その開始点候補は今回のRNA-seq証拠では原理上検出できず、判断保留22件の一部はこれが原因の可能性がある。追加サンプルを取得できれば解消する見込み。
- GCA/GCF比較(§9)は環境移行(ノートパソコン→デスクトップパソコン)を経て必要な環境(BAM・オルソログDB・samtools)が復元され、§9-Eの新規BLAST/RNA-seq計算まで完了した。残る課題は以下。
  - フレームシフト疑い6件中2件(MA_RS28585, MA_RS28795)は、両読み枠ともBLASTヒットが弱く「判断つかない」のまま。BLAST以外の証拠(実験的なN末端シークエンシング等)が無いと確定できない。
  - GCA提案位置の非正準コドン・読み枠内ストップコドンを理由に「支持しない」側へゲートした遺伝子(207件中18件、119件中20件)は、機械的な安全策による除外であり、個別の生物学的な妥当性は未検証。

## 9. GCA(GenBank旧版・2002年)とGCF(RefSeq現行版・2024年)アノテーションの比較

RNA-seq・BLASTに続く第3の証拠源として、*M. acetivorans*の原論文アノテーション(GCA_000007345.1、GenBank/INSDC、配列ID`AE010299.1`、genomenet経由で取得)を、現行のGCF_000007345.1(RefSeq、配列ID`NC_003552.1`)と比較した。

### 9-A. ゲノム配列の同一性確認

`AE010299.1`と`NC_003552.1`を1塩基ずつ比較した結果、**完全一致**(5,751,492bp、差異ゼロ)。両アノテーションの座標はそのまま直接比較できることを確認済み。

### 9-B. 開始位置の比較

`gene_biotype=protein_coding`の遺伝子同士を`old_locus_tag`でマッチングした。

| 項目 | 件数 |
|---|---|
| GCF protein_coding遺伝子 | 4,702 |
| GCA protein_coding遺伝子 | 4,540 |
| old_locus_tag経由でマッチ | 4,115 |
| うち開始位置が一致 | 2,808 |
| うち開始位置が不一致 | **1,307**(31.8%) |
| うちフレームシフト疑い(差分が3の倍数でない) | **6** |

**副次的な発見**: マッチしなかった39件のGCF protein_coding遺伝子は、GCA(2002年)側では偽遺伝子(pseudogene)として注釈されていた。2002年から現在までの間に「偽遺伝子→機能遺伝子」への再分類が39件発生していることになる。

### 9-C. 既存パイプライン結果との統合

全4,683遺伝子に`gca_start`列を追加して突き合わせた結果:

| gca_agrees_with | 件数 |
|---|---|
| 現行(GCF)と一致 | 2,808 |
| GCA比較不可(マッチなし・フレームシフト等) | 568 |
| BLASTと一致 | 441 |
| いずれとも異なる(第3の候補) | 439 |
| BLAST・RNA-seq両方と一致 | 394 |
| RNA-seqと一致 | 33 |

**「要確認」34件への影響**: GCA比較可能な23件のうち15件でGCAが既存証拠(主にBLAST支持位置、13件)と一致し、「中確信度相当(決着提案)」への格上げを提案。「判断保留」は22件→7件に縮小。アーティファクト判定した2件(MA_RS07375, MA_RS12405)もGCAはBLAST支持位置と一致しており、判定は維持しつつ「要再検討」を両論併記。

**「現行アノテーションを支持」3,427件への影響**: うちGCAと不一致だった336件について、ゲノム配列のみで妥当性チェック(区間内ストップコドンの有無・候補コドンの正準性)を実施。129件は根拠薄弱(非正準コドン、またはBLASTヒットなし)として除外、**残り207件は新規BLAST/RNA-seq計算が復元でき次第、優先的に再検証すべき候補**。

**「中確信度」1,109件への影響**: うちGCAと不一致だった849件のうち、**730件(66%)は既存の単独証拠(主にBLAST)とGCAが一致**しており、高確信度への格上げを提案。残り119件はGCAが一致せず中確信度を維持。

### 9-D. フレームシフト疑い6件

差分が3の倍数でない6遺伝子(MA_RS02220, MA_RS07005, MA_RS10350, MA_RS11040, MA_RS28585, MA_RS28795)は、開始位置だけでなく終止コドン位置も両アノテーション間で異なり、翻訳後のタンパク質配列が冒頭から完全に別物だった。単純な開始コドンの選び直しではなく、同一`old_locus_tag`に対して2つの注釈が異なるORF/読み枠を割り当てていることを意味する。両者とも自己完結したORFとして成立しており(内部ストップコドンなし)、どちらの読み枠が正しいかはBLAST照合(新規計算)なしには判断できない。

### 9-E. 新規BLAST/RNA-seq計算による最終再評価(完了)

環境移行(ノートパソコン→デスクトップパソコン)を経てRNA-seq BAM・オルソログ蛋白質DB・`samtools`が復元されたため、一時停止していた新規計算を実施した。判定ロジックは既存パイプラインの基準(ステップ比閾値3.0等)を踏襲し、加えて**GCA提案位置の候補コドンが非正準、または現行位置との間に読み枠内ストップコドンが挟まる場合は、BLAST/RNA-seqの数値がどうであれ「支持しない」側にゲートする安全策**を追加した。

**フレームシフト疑い6件**: 両読み枠(GCF/GCA)それぞれでBLAST照合を実施。

| 遺伝子 | 結論 |
|---|---|
| MA_RS02220, MA_RS07005, MA_RS11040 | GCF読み枠が妥当(オルソログとの一致度が高い) |
| MA_RS10350 | GCA読み枠が妥当 |
| MA_RS28585, MA_RS28795 | 判断つかない(両読み枠ともBLASTヒットが弱い) |

**「支持」336件中207件**(`FinalReports/gca_flagged_support_final.csv`): 現行支持のまま86件 / 中確信度相当へ格上げ120件 / 高確信度相当へ格上げ1件。

**「中確信度」849件中119件**(`FinalReports/gca_flagged_medium_final.csv`): 中確信度のまま76件 / 高確信度相当へ格上げ43件。

なお、GCA(2002年)とBLAST(現代のオルソログ相同性検索)はどちらも相同性ベースの推定であり、完全に独立な証拠ではない点は解釈上留意すること。

### 9-F. 最終的な確信度内訳(GCA統合後)

上記9-C・9-Eの結果を反映した、全4,683遺伝子の最終的な内訳(「要確認」34件は§6で個別に扱うため下表には元の分類のまま含む)。

| 元カテゴリ | 内訳(GCA統合後) |
|---|---|
| 現行アノテーションを支持(3,427件) | 支持のまま 3,306件 / 中確信度相当へ格上げ 120件 / 高確信度相当へ格上げ 1件 |
| 中確信度(1,109件) | 中確信度のまま 336件 / 高確信度相当へ格上げ 773件(GCA一致による既存730件+新規計算による43件) |
