# 開始コドン検証 — 判断保留23件 追加切り分け 指示書（Claude Code向け）

## 背景

「要確認」34件の深掘り(`review_34_reclassified.csv`)により、6 真の代替候補 / 5 アーティファクト / **23 判断保留** に分類済み。レビューの結果、この23件の中に構造の異なる2種類の保留理由が混在していることが分かった。それぞれ性質が違うため、別々に追加検証する。

## 対象データ

- `start_codon/full_run/review_34_reclassified.csv`(前回の34件深掘り結果、reclassification="判断保留"の23行)
- 各遺伝子のBAMカバレッジ(`rnaseq_requantification/bam/`の6サンプル)

---

## Task A: 「BLAST証拠が弱いために保留」グループの再評価

23件のうち、コメントが「BLASTのqstart=◯・同一性◯%は極めて弱く、実質的に独立支持とみなし難い」となっているケース(目視で約11件: MA_RS10510, MA_RS02100, MA_RS03935, MA_RS24755, MA_RS12145 等、該当するもの全て)は、**2つの証拠が対等に対立しているのではなく、実質的にRNA-seq単独の証拠しかない**状態に近い。

これは他の遺伝子群における「中確信度: 上流への延長の可能性(片方の証拠のみ)」1,109件と本質的に同じ状況のはずである。

1. 該当する行を機械的に抽出する基準を決める(例: `blast_pident < 85` かつ `blast_qstart_aa >= 30` など、既存コメントと矛盾しない閾値を`find_true_start_codons.py`内の既存ロジックから逆算して決めること。恣意的な閾値にならないよう、スクリプト内で実際に「BLAST証拠なし」と判定している基準と揃えるのが望ましい)。
2. 該当遺伝子について、RNA-seq側の証拠(deep at rna_best / deep at current の比率、rna_step_ratio)だけを根拠に「中確信度」相当まで格上げしてよいかを判断する。判断基準:
   - RNA-seq候補位置の深度比率が既存の「中確信度」判定と同水準かそれ以上であること
   - 深度の立ち上がりが単調減衰のテールでなく、明確なステップになっていること(前回のTask実施時に見た深度プロファイルを再利用してよい)
3. 格上げ可否とその理由を1行コメントとして追加し、`review_23_pending_reevaluated.csv`として出力する(元の17列 + `reevaluation`列["中確信度相当に格上げ" / "判断保留のまま"] + `reevaluation_comment`列)。

## Task B: 「70bp地点で深度が増加する」異常パターンの横展開チェック

前回、MA_RS17265で「70bp先の深度が候補位置より+451%増加しており、その先で別の高発現領域に近づいている可能性が高い」という指摘があった。これは他の判断保留ケースにも起きていないか、23件全てについて確認する。

1. 各遺伝子について、現行開始位置から**70bp・150bp・300bpの3地点**でのカバレッジ深度を追加取得する(既存の`depth_70bp_further`だけでなく、より遠方も見て「その先で別の転写物に近づいているだけ」なのか「本当にこの遺伝子の転写が続いている」のかを切り分ける)。
2. 深度が70bp地点以降で**単調減衰せず、再上昇または高止まりする**遺伝子をリストアップする(MA_RS17265と同じパターン)。これらは、たとえ現在「真の代替候補」や「中確信度」相当に見えても、実際には隣接する無関係な高発現領域の影響を受けている可能性があるため、既存の6件の「真の代替候補」判定も含めて再点検すること(23件だけでなく前回の34件全体に対してこのチェックを広げてよい)。
3. 該当した遺伝子とその深度推移(70bp/150bp/300bp)を表にまとめ、`depth_extended_check.csv`として出力する。
